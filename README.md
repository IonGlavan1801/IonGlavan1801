## About me

I'm a backend-focused PHP developer specializing in Laravel applications, from focused features and API integrations to complete SaaS and eCommerce platforms. I care about readable code, dependable business logic, secure payment flows, performance, and smooth handovers.

Laravel is my primary framework. I also work with Symfony, CodeIgniter, Vue.js, React, Inertia.js, Blade, Livewire, and the wider modern PHP ecosystem when the project calls for them.

## What I can build

- **SaaS platforms:** multi-tenancy, subscriptions, onboarding, roles and permissions, billing, email flows
- **eCommerce systems:** product catalogs, carts, checkout, coupons, invoices, inventory, order management
- **Payments:** Stripe, PayPal, subscriptions, refunds, webhooks, reconciliation and failure handling
- **Admin panels:** secure CRUD interfaces, dashboards, reports, analytics, CSV/PDF exports
- **REST APIs:** authentication, versioned endpoints, validation, notifications and third-party integrations
- **Maintenance:** bug fixing, refactoring, upgrades, legacy-code modernization and technical debt reduction
- **Performance:** query optimization, caching, queues, scheduled jobs, background processing and monitoring
